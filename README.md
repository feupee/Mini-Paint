# Mini-Paint

Versão modificada com interface visual inspirada no Paint clássico do Windows 95/98.

## Como executar

```bash
python main.py
```

## Alterações principais

- Barra de menu superior no estilo clássico.
- Barra lateral de ferramentas em duas colunas.
- Botões com borda 3D elevada/afundada.
- Área de desenho reposicionada dentro de uma moldura rebaixada.
- Barras de rolagem falsas apenas visuais.
- Paleta de cores inferior clicável.
- Barra de status inferior com coordenadas do mouse.

A moldura real da janela continua sendo controlada pelo sistema operacional. O visual antigo é simulado dentro da janela do Pygame.
